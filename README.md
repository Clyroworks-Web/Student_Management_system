# 🎓 Student Management System

A robust, standalone desktop application designed for local coaching centers and private tutors to efficiently manage student enrollments, courses, and administrative tasks. Built entirely in Python, it prioritizes offline data security, seamless user experience, and professional reporting.

## ✨ Key Features

* **Secure Authentication:** Administrator access is protected with industry-standard password hashing to prevent unauthorized access.
* **Email Verification (OTP):** Secure password recovery utilizing a two-factor email OTP system powered by Google App Passwords.
* **Local & Private Database:** All student and course data is stored locally using SQLite, ensuring complete data privacy, ownership, and zero recurring cloud hosting fees.
* **Modern User Interface:** A clean, responsive, and intuitive dark-mode interface built with CustomTkinter.
* **Data Management:** Easily track student details, course assignments, and enrollment statuses from a centralized dashboard.

## 🛠️ Technology Stack

| Component | Technology |
| :--- | :--- |
| **Language** | Python 3.x |
| **GUI Framework** | CustomTkinter |
| **Database** | SQLite3 |
| **Security** | hashlib (Password Hashing), smtplib (OTP Emails) |
